# MiG-15bis Flight Simulator Homecockpit

A custom engineering project focused on building a physical homecockpit for the **DCS World (MiG-15bis)** flight simulator. 

The goal of this project is to combine a passion for aviation with hardware engineering, embedded programming, and systems integration—emphasizing precision and a non-standard approach to structural problem-solving.

## About the Project
Instead of relying on commercial, off-the-shelf solutions, the majority of the instruments, control elements, and the structural frame are custom-designed, wired, and assembled from scratch. The cockpit interfaces with the simulator using custom microcontroller setups (Arduino) and DCS-BIOS.

## Current Status & Progress
Work is actively in progress, with periodic updates being added as new subsystems come online:

- [x] **Custom Flight Instruments:** Multiple gauges designed, assembled, and programmed.
- [x] **Bench Testing:** Functional tests completed for selected instruments *(see demo videos in the repository)*.
- [ ] **Main Instrument Panel (In Progress):** Currently cutting and fitting the structural front panel template where the instruments will be mounted.
- [ ] **Final Wiring & Systems Integration:** Connecting all sub-assemblies into the main cockpit frame.
